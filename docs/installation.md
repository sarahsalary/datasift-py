# Installation

## From PyPI

```bash
pip install datasift-py
```

## From source

```bash
git clone https://github.com/sarahsalary/datasift-py.git
cd datasift-py
pip install -e .
```

## Development

```bash
pip install -e ".[dev]"
pytest
```

## Documentation

```bash
pip install -e ".[docs]"
mkdocs serve
```

Then open http://127.0.0.1:8000 in your browser.
